# SeqREST

SeqREST is a REST API testing tool that uses a local LLM to
generate executable request sequences, reuse response-derived
resources, and mutate sequences and parameters.

## Download and usage

- [Download the tool package](https://github.com/QwQljh/SeqREST/releases)
- [English quick-start guide](seqrest/README.md)
- [中文使用说明](seqrest/README_zh.md)
- [Tool source code](seqrest/)

The `seqrest` directory contains the complete tool.
Place it under `tools/seqrest` in a RESTGym checkout.
